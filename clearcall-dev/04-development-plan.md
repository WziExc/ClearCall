# 04 — 分阶段开发计划

> **原则**：一次一个阶段，验收通过再进入下一阶段。不跳步、不并行多阶段。

---

## 路线总览

```
阶段0 ──→ 阶段1 ──→ 阶段2 ──→ 阶段3 ──→ 阶段4 ──→ 阶段5 ──→ 阶段6
项目初始化  Flutter    房间通话    好友系统   UI 打磨   测试与    发布与
+ 规范     + 基础 UI   (2-3人)    + 在线     + 动画    优化       后续迭代
                       + 通话功能   呼叫
```

| 阶段 | 名称 | 周期（预估） | 关键产出 |
|---|---|---|---|
| 0 | 项目初始化与规范 | 已完成 | 全部标准文件、CLAUDE.md |
| 1 | Flutter 项目 + 基础 UI | 1-2 周 | App 壳、Tab 导航、磨砂组件库 |
| 2 | 房间通话 + 完整通话功能 | 3-4 周 | 2-3人 P2P/Mesh 视频通话、名片、扬声器、PiP |
| 3 | 好友系统 + 在线呼叫 | 2-3 周 | 好友添加/列表/在线状态/FCM 推送 |
| 4 | UI 打磨与动画 | 1-2 周 | 动效、过渡、异常状态处理 |
| 5 | 测试与优化 | 1-2 周 | 单元/集成测试、性能优化、多设备兼容 |
| 6 | 发布与后续迭代 | 持续 | Google Play 上架、用户反馈迭代 |

---

## 阶段 2：房间通话 + 完整通话功能（核心）

### 目标
不依赖好友系统，实现通过 6 位房间号创建/加入房间，完成 2-3 人 P2P/Mesh 视频通话，以及完整的通话内功能。

#### 2-A：信令与 WebRTC 基础
- [ ] 2.1 实现 SignalingService 抽象接口
- [ ] 2.2 实现 FirebaseSignaling（创建房间/加入房间/信令交换）
- [ ] 2.3 配置 Firebase 项目（google-services.json + Realtime Database 规则）
- [ ] 2.4 实现 WebRTCService（初始化 PeerConnection / 采集本地流 / 设置远端流）
- [ ] 2.5 实现 CallManager（通话状态机：空闲→等待→通话中→结束）
- [ ] 2.6 配置 STUN/TURN ICE 服务器

#### 2-B：房间创建与加入
- [x] 2.7 实现"新建房间"逻辑（生成 6 位数字 / 写入 Firebase）
- [x] 2.8 实现"加入房间"逻辑（输入房间号 / 读取 Firebase / 建立连接）
- [x] 2.9 实现房间二维码生成与扫描加入
- [x] 2.10 实现房间等待超时（5 分钟无人加入自动关闭并提示）
- [x] 2.11 实现房间满员处理（第 4 人提示"房间已满"）

#### 2-C：通话界面与交互
- [x] 2.12 实现通话等待界面（显示房间号 + 等待好友 + 分享选项）
- [x] 2.13 实现 2 人通话界面（全屏对方 + 可拖拽自己小窗 + 网络指示 + 菜单按钮）
- [x] 2.14 实现 3 人通话界面（等分网格布局 + Mesh 组网 + 每格名片触发）
- [x] 2.15 实现底部控制栏（静音/补光/摄像头/扬声器/翻转/挂断/齿轮 共 7 个）
- [x] 2.16 实现扬声器切换面板（iPhone 风格磨砂弹出）
- [x] 2.17 实现通话菜单按钮（右上角 ☰ → 名片 / 设置）
- [x] 2.18 实现通话中名片条（菜单或轻触触发，底部磨砂滑出，3秒消失，非好友可添加）
- [x] 2.19 实现前置补光（屏幕边缘白色渐变高亮，控制栏 💡 触发，暗光检测）
- [x] 2.20 实现视频静画（摄像头关闭显示圆角头像 + 纯黑背景）
- [x] 2.21 实现网络质量指示（左上角 8dp 模糊圆点 绿/黄/红，点击展开延迟丢包数值）
- [x] 2.22 实现通话设置面板（底部半屏，实时调整分辨率/帧率/画质偏好/音频编码/处理开关）
- [x] 2.23 实现 H.265/HEVC 检测与切换（设备硬编能力检测，SDP 协商降级）
- [ ] 2.24 实现摄像头档位记忆（SharedPreferences 持久化全部设置）
- [ ] 2.25 实现挂断按钮（红色醒目）及画面缩小消失动画
- [ ] 2.26 实现通话时长计时器
- [ ] 2.27 实现画中画（PiP）模式（按 Home 键自动切换悬浮窗）
- [ ] 2.28 实现蓝牙耳机自动切换（WebRTC 默认行为确认）

#### 2-D：通话记录、报告与权限
- [ ] 2.29 实现本地通话记录存储（sqflite + 列表 UI）
- [ ] 2.30 实现通话呼叫音效（系统铃声 + 自定义轻柔呼叫音效）
- [ ] 2.31 实现通话结束报告（挂断后磨砂卡片：对象/时长/质量/流量/优化建议）

### 验收标准

- [ ] 静音、摄像头开关、补光、扬声器切换、翻转镜头、挂断均正常
- [ ] 网络质量圆点正确显示绿/黄/红，点击展开延迟丢包数值
- [ ] 菜单按钮弹出名片和设置入口，名片条可查看并添加好友
- [ ] 通话设置面板实时生效（分辨率/帧率/画质偏好/音频开关）
- [ ] H.265 设备检测正确，不支持时开关置灰
- [ ] 通话结束后弹出质量报告卡片，质量/流量/建议正确

- [ ] 第 4 人加入时提示"房间已满"
- [ ] 通话记录正确存储在本地
- [ ] PiP 模式下通话不中断
- [ ] 同一 Wi-Fi 下延迟 < 200ms
