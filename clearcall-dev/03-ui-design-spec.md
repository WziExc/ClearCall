# 03 — UI 设计规范

> **设计原则**：iOS 式极简主义，毛玻璃背景，半透明元素，淡灰色调。  
> **参考风格**：Apple FaceTime / iOS 系统应用

---

## 一、设计原则

1. **克制**：每个界面不超过 3 个主操作
2. **透明层次**：用模糊和透明度表达层级，而非阴影
3. **大留白**：内容区域四周留白 16dp，元素间距慷慨
4. **系统感**：使用系统默认无衬线字体，不做花哨的排版

---

## 二、色彩系统

| 名称 | 色值 | 用途 |
|---|---|---|
| 主背景 | `#F2F2F7` | 页面底色（iOS 系统背景灰白） |
| 卡片/控件背景 | `rgba(255,255,255,0.8)` + `backdrop-filter: blur(20px)` | 磨砂卡片 |
| 主强调色 | `#007AFF` | 接通、确认、链接、选中状态 |
| 危险色 | `#FF3B30` | 挂断、删除、拒绝 |
| 成功色 | `#34C759` | 在线状态指示灯 |
| 警告色 | `#FF9500` | 通话中状态指示灯 |
| 中性色 | `#8E8E93` | 离线状态指示灯、占位文字 |
| 文字主色 | `#1C1C1E` | 标题、正文 |
| 文字次级 | `#8E8E93` | 次要说明、时间戳 |
| 分割线 | `#E5E5EA` | 列表分割、细线 |

### 暗色模式适配（后续版本）
- 主背景：`#000000`
- 卡片背景：`rgba(28,28,30,0.8)`
- 文字主色：`#FFFFFF`

## 四、组件规范

### 4.1 磨砂卡片（GlassCard）
```css
background: rgba(255, 255, 255, 0.8);
backdrop-filter: blur(20px);
-webkit-backdrop-filter: blur(20px);
border-radius: 16dp;
border: 1px solid rgba(255, 255, 255, 0.3);
```

### 4.2 磨砂按钮（GlassButton）
- 默认状态：`rgba(255,255,255,0.8)` 磨砂背景，圆角 50dp（胶囊形）
- 按压态：scale 0.95，背景加深至 `rgba(255,255,255,0.95)`
- 危险变体（DangerButton）：背景 `#FF3B30`，磨砂遮罩
- 图标大小：28pt，线条 2px
- 按钮高度：56dp

### 4.3 列表项（ListItem）
- 高度：64dp
- 水平内边距：16dp
- 圆角：12dp
- 背景：白色磨砂卡片
- 分割线：`#E5E5EA`，1px，左留白 72dp（对齐文字）

### 4.4 彩色头像（ColorAvatar）
- 直径：48dp（列表）/ 64dp（详情）
- 圆角：正圆
- 背景色：根据昵称哈希值从预设 12 色调色板中选取
- 文字：昵称首字母大写，白色，字号 20sp（列表）/ 28sp（详情）

### 4.5 状态指示灯
- 尺寸：12dp 直径
- 位置：头像右下角
- 在线：`#34C759`（绿色）
- 离线：`#8E8E93`（灰色）
- 通话中：`#FF9500`（橙色）

### 5.3 网络质量指示

通话界面左上角（或安全区域内），不遮挡画面主体：

```
🟡  ← 8dp 直径圆点，边缘高斯模糊 2dp
```

| 颜色 | 条件 | 含义 |
|---|---|---|
| 🟢 绿色 `#34C759` | RTT < 100ms，丢包 < 2% | 优秀 |
| 🟡 黄色 `#FF9500` | RTT 100-300ms，丢包 2-5% | 一般 |
| 🔴 红色 `#FF3B30` | RTT > 300ms 或丢包 > 5% | 差 |

- 点击圆点 → 展开小型浮动面板，显示延迟/丢包数值（13sp 灰色小字）
- 面板背景磨砂，3 秒自动收起
- 无文字标签，纯图标表达

```
│                      ┌────────┐ │
```

**选项：**
- **👤 名片**：点击展示当前通话对象的名片条（含头像/昵称/状态/添加好友）

**报告规范：**

- 动画：从中心 scale 0.8 → 1.0 + fade in（300ms spring）
- 质量评级：

| 等级 | 图标 | 条件 |
|---|---|---|
| 优秀 | 🟢 绿色 | RTT < 50ms 且丢包 < 1% |
| 良好 | 🟡 黄色 | RTT 50-200ms 或丢包 1-3% |

  - "延迟较高，可能影响通话体验"（RTT > 200ms）
  - "对方网络环境较弱"（对端丢包 > 5%）
  - 质量优秀时不显示建议

```
└─────────────────────────────────┘
```

**麦克风被拒绝时 — 通话中提示：**
- 通话界面顶部滑入黄色提示条："麦克风已关闭，对方无法听到你的声音"
- 高度：40dp，背景 `rgba(255,149,0,0.15)`，文字 13sp
- 3 秒后自动消失，可被下滑手势关闭

**通知被拒绝时 — 首次出现提示：**
- "我"页面顶部显示提示卡片："开启通知以接收来电提醒"
- 磨砂卡片，右侧"去开启"蓝色按钮
- 用户关闭后不再显示
