# 00 — 项目概述

---

## 项目名称
**ClearCall**

## 一句话描述
一款运行在安卓手机上的极简视频通话工具，不注册、不加好友即可通话。

## 项目定位
- **目标用户**：需要简单私密视频通话的任何人（家人、小团队、情侣）
- **核心场景**：2-3 人小群组私密视频通话
- **差异化**：零注册门槛、无自有服务器、数据不经第三方

## 核心卖点
1. **零门槛**：打开 App 就能创建房间，6 位数字房号即可加入
2. **真私密**：音视频数据 P2P 直传，不经任何服务器
3. **轻好友**：无需注册账号，本地唯一 ID + 云端信令实现好友关系
4. **极简美学**：Apple 风格毛玻璃设计，操作直觉化

## 目标平台
- 优先：Android 8.0+
- 未来：iOS 15+

## 技术路线
- **框架**：Flutter 3.x（Dart）
- **音视频**：WebRTC P2P（flutter_webrtc）
- **信令主方案**：Firebase Realtime Database（海外）
- **信令备选方案**：Leancloud（国内）
- **穿透**：Google STUN + Metered.ca TURN（免费层 fallback）
- **推送**：FCM（Firebase Cloud Messaging）

## 无服务器承诺
- 不搭建任何自有服务器
- 所有后端能力来自 Firebase / Leancloud 免费层
- 音视频数据 100% P2P

## 项目限制
- 最多 3 人同时视频（Mesh 模式限制，超过 3 人需要 SFU 服务器）
- 不提供文字聊天功能（聚焦视频通话）
- 依赖 Google Play 服务（Firebase）/ 或不依赖（Leancloud 方案）
- 对称 NAT 环境下可能需要 TURN 中继（免费额度内）
